## Prop Trip
Developed for the UJI Game Jam 2024 with the theme "Anything is a weapon". It is a first-person high-speed shooter and platformer. I served as game designer, composer and audio designer. [Play today!](https://punicgoose.itch.io/prop-trip) 

The standout feature I developed for this game was a dynamic music system built entirely within the Unity audio engine. This project explores the concept of adaptive game music: as the player fights, loses health, or consumes different substances, new musical layers are seamlessly introduced. This system shifts the soundtrack from a high-paced ambient track into an intense rave, directly reflecting the chaos of the gameplay.
