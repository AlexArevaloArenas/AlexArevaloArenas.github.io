# Mini Mobile Adventure
Developed for Introduction to Game Design course in Algoma University, in the year 2023. It works as a simple prototype of a zelda-like adventure game in mobile games, using pixel art sprites.
[Play now!](https://alex-perritos.itch.io/mini-mobile-adventure)
